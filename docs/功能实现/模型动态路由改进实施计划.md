# 模型动态路由改进实施计划

## 1. 实施目标

将现有 Shadow 动态路由以可回退方式接入生产选择，使用“硬约束 + 最便宜充分模型”替代旧关键词组合路由，同时保持用户显式模型优先。

首期只实现单次调用前路由，不实现模型级联、在线学习或运行时多 Provider 故障转移。

## 2. 设计原则

1. 当前任务优先，Agent 和工作流阶段只做必要调整。
2. 硬约束先于软能力选择。
3. 先判断能力是否充分，再比较成本。
4. 不确定任务默认 Balanced，高风险任务升级 Reasoning。
5. 保持 Shadow 开关，支持对比旧路由并安全灰度。
6. 新路径稳定后直接删除旧策略，不维护兼容层。

## 3. 首期范围

### 3.1 路由结果

新增或复用结构化决策结果，至少包含：

- selected model；
- selection source；
- requested operating mode；
- task type；
- 充分性判断依据；
- 被硬约束拒绝的候选；
- 选择原因与可观测指标。

### 3.2 显式模型

- 显式模型存在、启用、Provider 可解析且满足当前请求的 Vision、上下文和输出硬约束时直接使用。
- 显式模型无效时抛出可诊断异常，不静默替换成自动模型。

### 3.3 自动模型

1. 使用现有 `RoutingContextFactory` 和 `RoutingRequirementService` 提取请求需求。
2. 使用现有 Catalog 和 Constraint Filter 过滤不可执行模型。
3. 根据任务和风险生成 `FAST_SAFE`、`BALANCED_DEFAULT` 或 `REASONING_REQUIRED`。
4. 对关键能力维度进行充分性判断，不再仅依赖总分补偿。
5. 在充分候选中按预计成本升序选择；平局时依次比较能力余量、稳定模型 ID。
6. 没有充分候选时选择能力匹配最高的合格模型并记录升级原因。

### 3.4 Agent 与阶段

- 修正 Agent policy：不得让 `SIMPLE_EDIT`、`FORMAT` 等简单任务无条件继承高结构化、高推理底线。
- `CustomConfigPlugin` 不再传固定 `UNKNOWN`，应从当前调用上下文中取得已有阶段信息；若项目没有可靠阶段来源，保持未知但不得据此虚构要求。

### 3.5 生产切换

- 保留旧路由作为配置级回退，不增加双写抽象。
- 新增明确配置开关控制动态路由是否接管生产。
- 默认保持安全的 Shadow 状态；测试通过后由环境配置开启。
- 动态路径异常时记录原因并回退旧路由；显式模型无效不允许回退。

## 4. 不在首期范围

- Embedding、向量数据库和训练分类器。
- 在线 Bandit 或自动修改权重。
- Top 3 并行推理、投票或答案融合。
- 生成结果级联验证。
- Provider 429/5xx 的跨模型自动重试。
- 前端协议和数据库结构变更。

## 5. 测试计划

最小测试集必须覆盖：

1. 普通简单编辑选择 Flash/最低成本充分模型。
2. Analyst 中的简单编辑不再因 Agent 固定底线被升级。
3. 复杂诊断选择 Reasoning 级充分模型。
4. Draw.io 生成选择满足 structured-output、tool-calling 和输出限制的模型。
5. 模糊请求不进入 Fast。
6. 当前轮图片严格过滤 Vision 非 `SUPPORTED` 模型。
7. 长上下文过滤窗口不足模型。
8. 有效显式模型优先。
9. 不存在、禁用或违反硬约束的显式模型明确失败。
10. 新动态路径关闭或异常时，非显式请求回退旧路由。
11. 排序结果稳定，不依赖候选输入顺序。
12. Top 3 仍仅为遥测，不触发多个模型调用。

## 6. 验收标准

- 所有现有路由测试与新增测试通过，0 failures、0 errors。
- 简单任务中 Fast 能在满足需求时自然成为 Top 1，不使用配额或特殊加分。
- 强模型数量增加不会改变“最低成本充分模型”的选择结果。
- 硬约束和有效显式覆盖规则有明确测试。
- 生产一次请求只设置一个模型。
- 无新增第三方依赖。
- 业务改动集中在现有 routing、catalog、scoring 和 `CustomConfigPlugin` 边界内。

## 7. 后续阶段

首期积累足够 Shadow 与真实质量数据后，再单独评审：

1. Draw.io XML/JSON 确定性校验驱动的 Fast-first 级联。
2. 基于真实偏好数据的轻量学习路由器。
3. Provider 健康度、延迟和故障域感知的运行时回退。

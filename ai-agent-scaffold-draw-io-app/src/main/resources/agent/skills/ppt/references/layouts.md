# PPT 布局模板

## 工作流程

1. 先确定总页数、叙事顺序和每页唯一核心结论。
2. 按信息关系选布局，不按页码机械轮换模板。
3. 先放标题和主要内容区，再放图标、分隔线与少量装饰。
4. 根据 `13.33 × 7.5` 画布计算每个元素的 `x/y/w/h`。
5. 应用同一技能中的 `colors.md` 和 `typography.md`，最后检查页数、边界和重叠。

## 支持的布局

| layout | 用途 |
| --- | --- |
| `title_slide` | 封面、章节开场 |
| `content_slide` | 左侧主题区 + 右侧正文 |
| `content_top` | 顶部标题 + 下方内容 |
| `card_3col` | 三个同级概念或方案 |
| `card_2col` | 两个同级主题 |
| `comparison` | 两项对比、前后对比 |
| `timeline` | 时间、阶段、里程碑 |
| `quote_slide` | 金句、核心观点、问题引入 |
| `data_highlight` | KPI、成果和关键数字 |
| `end_slide` | 总结、行动项、致谢 |

不要输出前端不支持的 layout 名称。五页以上至少使用三种布局，但连续内容强相关时优先保持一致。

## 元素契约

| kind | 必需字段 | 用途 |
| --- | --- | --- |
| `text` | `content,x,y,w,h,fontSize,color` | 标题、正文、说明 |
| `table` | `content,x,y,w,h,rows` | 有明确行列关系的数据 |
| `icon` | `content,x,y,w,h,fontSize,color` | 视觉锚点，优先简洁 emoji |
| `divider` | `x,y,w,h,color,thickness` | 区域分隔 |
| `bullet` | `content,x,y,w,h,number,fill` | 有序步骤和要点 |
| `shape` | `x,y,w,h,fill` | 背景块和少量强调装饰 |
| `image` | `content,x,y,w,h` | 可访问的图片 URL |

所有颜色均为不带 `#` 的 6 位十六进制。坐标和尺寸单位为英寸。

## 布局规则

- 严格输出用户要求的页数；内容过多时重新分配，不丢页、不塞满。
- 每个内容页至少包含一个图标、编号要点、数据视觉或图片，避免纯文本墙。
- 每页只保留 3–5 个核心信息点；卡片数量必须与布局列数一致。
- `x >= 0`、`y >= 0`、`x + w <= 13.33`、`y + h <= 7.5`。
- 标题、正文、装饰之间不能重叠；分隔线不得穿过文字。
- 图片 URL 必须真实可访问；无法确认时使用明确占位，不伪造外部地址。
- 装饰元素服务于层级，不得比内容更醒目。

## 输出与完成检查

- 输出合法 JSON，不包含注释、Markdown 代码围栏或额外说明。
- 每页包含连续且唯一的 `slideIndex`、受支持的 `layout` 和 `elements`。
- 元素字段类型正确，字符串正确转义，颜色和坐标格式一致。
- 检查总页数、布局多样性、元素重叠、越界、文字密度和主题一致性。

# PPT 配色

## 工作流程

1. 根据主题、受众和场合选择一套主题；整份 PPT 不混用主题。
2. 按 60% 主色、30% 辅助色、10% 强调色控制面积占比。
3. 先保证文字可读性，再考虑装饰性；深色背景文字使用 `FFFFFF`。
4. 将强调色只用于关键数字、状态、分隔线和少量视觉焦点。
5. 输出前检查每页的主题一致性、对比度和颜色格式。

所有主题的深色区域标题色均为 `FFFFFF`。辅助信息可使用 `AAAAAA` 或主题的低对比灰色。

## 应用规则

- 颜色字段使用 6 位十六进制值，不带 `#`。
- 主色用于头栏、封面、主要形状和表头；中间色用于次级区域；浅色用于图标或层级区分。
- 强调色占比不得超过约 10%，不要作为大面积正文背景。
- 正文避免纯黑 `000000`，优先使用主题 `body`；说明文字使用 `sub`。
- 同一语义保持同色，例如成功、警告、失败不要在不同页面随意换色。
- 不以红绿差异作为唯一信息载体；同时加入文字、图标或形状。

## 完成检查

- 一份 PPT 只选用一套主题。
- 深色背景与浅色文字、浅色背景与深色文字具备清晰对比。
- 强调色聚焦少数关键信息，没有喧宾夺主。
- 所有颜色格式合法，未出现 `#`、3 位色值或主题外随机色。

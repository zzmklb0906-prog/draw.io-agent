# PPT 排版

## 工作流程

1. 每页先确定一个核心结论，再建立标题、重点、正文三个以内的视觉层级。
2. 根据元素角色分配字号、字重和对齐，不用多种字体制造层级。
3. 计算安全区和元素间距，确保文字不溢出、元素不重叠。
4. 精简长段落为短句或要点；内容过多时拆页，不缩小到难以阅读。
5. 输出前检查字号、行数、对齐、一致性和边界。

## 字号体系

| 元素 | 字号 |
| --- | --- |
| 封面主标题 | 40–48 |
| 封面副标题 | 20–24 |
| 内容页标题 | 24–30 |
| 正文要点 | 15–18 |
| 卡片标题 | 18–22 |
| 卡片说明 | 13–15 |
| 表格/辅助信息 | 12–14 |
| KPI 大数字 | 36–52 |

## 布局与密度

- 16:9 画布为 `13.33 × 7.5` 英寸。
- 安全区：`x >= 0.8`、`x + w <= 12.5`、`y >= 0.2`、`y + h <= 7.1`。
- 标题与正文至少间隔 `0.4` 英寸；左右分栏至少间隔 `0.3` 英寸。
- 每页保留 3–5 个核心信息点；单个要点尽量不超过两行。
- 一页最多三个字号层级；仅对标题、关键词和关键数字加粗。
- 页面标题与正文默认左对齐；封面标题、KPI 与短卡片内容可居中。

## 字体与文本

- 中文优先使用 `Microsoft YaHei`；若交付环境未安装，使用项目统一的无衬线后备字体。
- 同一份 PPT 使用同一字体族，不混用装饰字体和正文字体。
- 流程步骤使用有序编号；并列要点使用项目支持的 `bullet` 元素。
- 避免全大写英文、整段加粗、连续长段落和超过两级的嵌套列表。
- 文本框高度应覆盖预计行数，并保留上下内边距。

## 完成检查

- 没有文本溢出、裁切、重叠或超出安全区。
- 标题、正文、说明的层级在每页保持一致。
- 正文不小于 12，关键信息无需放大页面即可阅读。
- 页面留白充足，内容拆分依据语义而不是平均塞满。

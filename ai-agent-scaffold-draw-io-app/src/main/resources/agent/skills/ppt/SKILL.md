# PPT 演示文稿

## 按需读取规范

- 规划页面结构、选择布局或生成元素 JSON：读取 [references/layouts.md](references/layouts.md)。
- 用户指定视觉主题、需要选择配色或检查对比度：读取 [references/colors.md](references/colors.md)。
- 生成文字内容、设置字号、留白、对齐或检查文本密度：读取 [references/typography.md](references/typography.md)。

制作完整 PPT 时通常需要三份规范，但应按“布局 → 配色 → 排版”的顺序读取；仅修改某个方面时只读取对应 reference。

## 通用工作流程

1. 明确主题、目的、受众、页数、语言、风格和交付格式。
2. 建立整套叙事结构，为每页定义一个核心结论。
3. 读取布局规范并生成页面骨架。
4. 读取配色与排版规范，统一主题、层级、密度和安全区。
5. 输出前检查页数、JSON 合法性、布局支持、重叠、越界和视觉一致性。

## 通用约束

- 严格满足用户要求的页数，不遗漏页面；内容过多时重新分配。
- 16:9 画布为 `13.33 × 7.5` 英寸，所有元素必须位于画布内且互不重叠。
- 每页聚焦一个结论并保留 3–5 个核心信息点，避免纯文字墙。
- 输出必须使用前端支持的布局、元素类型和字段，不自行发明协议。
- 结构化输出必须是合法 JSON，不包含注释、Markdown 围栏或额外说明。
- 不伪造图片 URL、数据来源或用户未提供的事实。

# PDF 处理

## 工作流程

1. 明确输入文件、目标输出、页面范围、是否为扫描件以及是否需要保留版式。
2. 先检查可用工具和 PDF 类型，再选择最小可行方案。
3. 在临时或新文件中生成结果，不覆盖原文件，除非用户明确要求。
4. 处理后验证页数、文本可读性、表单值、边界框和文件可打开性。
5. 告知输出位置、处理范围以及未能保留的特性。

## 工具选择

| 任务 | 首选工具 |
| --- | --- |
| 合并、拆分、旋转、元数据、加密 | `pypdf` 或 `qpdf` |
| 保留布局的文本与表格提取 | `pdfplumber` |
| 创建排版 PDF | `reportlab` |
| 扫描件 OCR | `pdf2image` + `pytesseract` |
| 图片提取 | `pdfimages` |
| 表单识别与填写 | 先阅读 [forms.md](forms.md)，优先使用 `scripts/` 中已有工具 |

高级库选择、命令示例和故障排查见 [reference.md](reference.md)。仅在任务需要对应能力时读取引用文件。

## 安全与质量要求

- 不假设依赖已安装；执行前检查命令或 Python 包是否可用。
- 密码、个人信息和表单内容不得写入日志或示例输出。
- OCR 结果必须声明可能存在识别误差；关键字段应抽样核对。
- 批量处理先用少量页面验证方案，再扩展到完整文件。
- 填表后运行字段和边界检查；必要时生成验证图片进行目视确认。
- 保留原始文件，输出使用可区分的文件名。

## 完成检查

- 输出文件存在且可被 PDF 解析器重新打开。
- 页数、页面顺序、旋转方向和目标范围正确。
- 文本、表格或表单字段没有明显截断、乱码或错位。
- 加密、解密或水印结果符合用户要求且未泄露凭据。
